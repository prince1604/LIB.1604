## ⚙️ How to Use This Repository

You can easily read these books online directly through GitHub, or download the entire collection to your local machine for offline reading.

### Option 1: Quick Download (ZIP)
1. Click the green **`<> Code`** button at the top right of this page.
2. Select **`Download ZIP`**.
3. Extract the folder and start reading!

### Option 2: Clone via Git (Recommended for updates)
Run the following command in your terminal to clone the massive library locally:
```bash
git clone https://github.com/prince1604/LIB.1604.git
```
*Tip: To pull the latest books in the future, simply navigate to the folder and run `git pull`!*
